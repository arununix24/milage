# Car Mileage Calculator

A responsive web-based application that calculates a vehicle's fuel efficiency based on distance traveled and fuel consumed, and helps plan trips by estimating required fuel and costs.

## Features

### Fuel Efficiency Calculator
- Calculate fuel efficiency in km/l or mpg
- Support for different units (kilometers/miles and liters/gallons)
- Calculate total fuel cost based on entered price (optional)
- Input validation to prevent invalid calculations
- Clear error messages for invalid inputs

### Trip Planner
- Calculate total fuel required for a planned trip
- Estimate the fuel cost based on current prices
- Support for different distance, efficiency, and price units
- Automatic unit conversion for consistent calculations

### Currency Support
- Multiple currency options (USD, EUR, GBP, JPY, INR, CAD, AUD)
- Currency symbols automatically displayed with cost results
- Independent currency selection for each calculator

### User Interface
- Tabbed interface for easy switching between calculators
- Responsive design that works on both mobile and desktop devices
- Modern, clean UI with intuitive controls
- Clear presentation of calculation results

## How to Use

### Fuel Efficiency Calculator
1. Enter the distance your vehicle has traveled (in kilometers or miles)
2. Enter the amount of fuel consumed (in liters or gallons)
3. Optionally enter the fuel price and select the currency
4. Select the appropriate units from the dropdown menus
5. Click "Calculate" to see your vehicle's fuel efficiency and total cost
6. Use the "Reset" button to clear the form and start over

### Trip Planner
1. Enter the total distance of your planned trip (in kilometers or miles)
2. Enter your vehicle's fuel efficiency/mileage (in km/l or mpg)
3. Enter the current fuel price per liter or gallon
4. Select your preferred currency
5. Click "Calculate Trip" to see the estimated fuel required and total cost
6. Use the "Reset" button to clear the form and start over

Simply open the `index.html` file in any web browser to use the application. No server or installation is required.
